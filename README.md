# My Life / 我的一生

## 它从一次和爷爷聊天开始

我想帮爷爷把他的人生记录下来。

他很激动，接着又说：“我文化不行，写不出东西。”

我突然意识到，今天记录一生的成本已经可以低到只剩下说话。一个人不需要会写作，不需要先理清年份，也不需要知道怎样使用 AI。他只要愿意讲，剩下的整理工作可以交给 Agent。

所以我做了“我的一生”。

它最初是给爷爷的。后来妈妈听说了，也说她想用。于是我不再把它限定为“老年人的应用”：每个人都经历过一些不该随着记忆一起消失的事。

## 打开以后是什么感觉

第一次打开只需要连接自己的 AI 服务。

![第一次连接记忆助手](docs/onboarding-browser-check-render.png)

设置完成后，进入的就是一个安静的对话框。没有要填完的表格，也没有要求从出生讲起。屏幕上只有一句：

> 想起什么，就从哪里讲起。

点一下语音按钮就可以开始说。转录文字会实时出现在输入框里，听错的地方可以直接修改。讲完一小段，可以先发送给 Agent 整理，但录音不会因此结束；不用对着屏幕一次讲上很久。

每一轮，Agent 会先给一条简短回应，让人知道它真的听到了。随后它自己判断该搜索哪些旧内容，把新讲述整理进：

- “我的一生”：按自然时间词排列的故事段落
- “我认识的人”：可以展开和修改的人物卡片
- “我去过的地方”：可以展开和修改的地点卡片

讲述不需要有顺序。用户说的也不一定都是故事，可能是在纠正一个名字、要求删掉一段、改一种说法，或者只是继续聊天。Agent 负责理解这些差别；用户的要求和亲手修改始终优先。

如果整理错了，直接点开修改就好。原始录音和原始转录仍然留在设备里，不会因为 Agent 改写了一个段落而消失。

## 它想做的事

“我的一生”不是替人自动生成一部看起来完整的传记。

它更像一个长期的记忆维护助手：安静地听，尽量不遗漏，把散落的话慢慢放回时间线、人物和地点中。等内容积累得足够多，再把它们变成书、照片或其他形式。

这个项目开源，也不打算依靠人们的回忆赚钱。

## 给想自己运行的人

项目没有 API 中继，也没有内置 API Key。应用从设备直接连接用户选择的服务；服务商会收到完成本轮转录与整理所需的相关文字或音频。

记忆 Agent 支持 OpenRouter、OpenAI、阿里云百炼和自定义 OpenAI-compatible endpoint。Android 实时转录可以使用阿里云 `qwen3-asr-flash-realtime`；iPhone 使用 Apple Speech。界面支持简体中文、繁體中文和 English。

记忆内容与录音保存在应用目录。API Key 在 Android 使用 Keystore 加密，在 iPhone 使用 Keychain。

- “聊一聊”导出完整 JSON 状态与独立 WAV 录音附件
- “我的一生”“我认识的人”“我去过的地方”分别导出对应的 Markdown

### 本机运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm test
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。

构建 Android APK 还需要 JDK 21 和 Android 36 SDK：

```bash
npm run android:debug
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

在 macOS 上构建 iPhone 客户端：

```bash
npm run ios:sync
open ios/App/App.xcodeproj
```
