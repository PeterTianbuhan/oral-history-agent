# 我的一生

## 背景

我想帮爷爷把他的人生记录下来。

他很激动，接着又说：“我文化不行，写不出东西。”

我突然意识到，今天记录一生的成本已经可以低到只剩下说话。一个人不需要会写作，不需要先理清年份，也不需要知道怎样使用 AI。他只要愿意讲，剩下的整理工作可以交给 Agent。

所以我做了“我的一生”。

它最初是给爷爷的。后来妈妈听说了，也说她想用。于是我不再把它限定为“老年人的应用”：每个人都经历过一些不该随着记忆一起消失的事。

## 已经在使用 Agent

## 给不愿意尝试 GPT 的爷爷奶奶

给他们安装“我的一生”App。打开以后，他们只需要说话，App 会把讲述慢慢整理成时间线、人物和地点。

[下载 Android 安装包](https://github.com/PeterTianbuhan/oral-history-agent/releases/latest/download/my-life-android.apk)。

## 记忆留在自己手里

讲述的原话、录音和整理后的记忆保存在自己掌握的设备或目录里，可以随时阅读、修改、导出和带走。
